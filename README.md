# Flight Dynamics Lab

原创中文交互式飞行力学网站。当前覆盖 **Phase 1–5**：14 节课程、43 道原创题、15 组实验，从飞行直觉延伸到静稳定、动态模态与简化飞行控制。使用 React、严格 TypeScript、Vite、Tailwind CSS、Three.js/React Three Fiber、KaTeX、Recharts。

## Windows 快速启动与更新

在 GitHub 选择 **Code → Download ZIP**，将整个 ZIP 解压，再双击 `windows-start.cmd`。脚本检查 Node.js 22.12+，必要时尝试用 winget 安装 Node.js LTS，安装锁文件依赖、运行类型检查和所有单元测试，然后启动网站并打开浏览器。保持终端窗口开启；按 Ctrl+C 停止。

若 winget 不可用，从 https://nodejs.org/ 安装 Node.js LTS（包含 npm），重新运行脚本。详见 `docs/Windows启动说明.txt`。脚本未在实际 Windows 机器验证；项目在 Linux 云环境通过模型测试和 Chromium 浏览器验收。

从旧版本更新：先停止原来的服务器，下载最新 ZIP 并解压到新的文件夹，运行启动脚本。保持相同浏览器及访问地址（默认 `http://localhost:5173`），原有本地学习进度会保留。localStorage 按地址隔离；换浏览器、主机名、端口或清除浏览器数据会改变进度存储。

## 课程与实验

| 阶段 | 课程所在级别 | 课程数 | 实验数 | 内容 |
| --- | --- | ---: | ---: | --- |
| Phase 1 | Level 1 | 1 | 3 | 四力、迎角与升力、三轴姿态 |
| Phase 2 | Level 2 | 5 | 4 | 动压、极曲线、平飞、爬升/滑翔、协调转弯 |

阶段是交付分组，Level 是知识层次；例如 Phase 4 同时包含运动方程和动态稳定性。每课提供观察、预测、解释、逐步公式、实验、独立答题与总结。滑块与数值输入、模型边界、带单位曲线、参数/时程比较和 CSV 支持反复验证；时间仿真实验提供运行、暂停、单步与重置。

“在线答题”有 43 道原创题，支持综合、级别、课程、错题筛选，以及答题卡、补答、交卷、成绩、解析和重做。数值题明确单位与容差，空白和非法输入不算正确。草稿与成绩独立保存，刷新后可继续；旧学习进度保留，预测、实验和题目掌握共同决定课程完成。

提供六级目录、前置知识提示、Hash 路由与浏览器返回、浅深主题、手机布局和无障碍标签。课程开放表示已有对应教学内容，不表示六级大纲的所有专题都已讲完。

## 模型、假设与基准

**所有飞机参数均是假设教学示例，不代表真实飞机或经过风洞标定的数据。** 内部力、速度、质量等用 SI；展示角用度，三角计算明确转为弧度。各实验模型独立，系数与操纵符号以当前页面为准，不能直接拼成同一架飞机。

Phase 1：CL = 0.2 + 0.08α（α 以度表示，−10° 至 15°）；15° 后连续指数下降仅为失速示意。CD = 0.025 + 0.055CL²。四力模型固定来流/迎角，二维增量 z 向上，不能当作自由飞行或 6DOF。三维矢量和位移缩放/限幅，读数保留计算值。姿态使用机体 x 前、y 右、z 下及 NED 世界，内禀 yaw-pitch-roll，渲染转换为四元数，俯仰限于 ±80°。

Phase 2：CD = CD0 + kCL²，默认 CD0=0.025、k=0.055、CLmax=1.4，m=1000 kg、S=16 m²、ρ=1.225 kg/m³、V=50 m/s。无风、固定密度、不可压缩、忽略系数与马赫数/雷诺数关系；推力假设与速度无关且沿航迹。

- 最佳升阻比：CL*=√(CD0/k)，Emax=1/(2√(CD0k))。显示 CLmax 内可实现的值；解析最佳速度超出实验范围会提示。
- 平飞：L=W，所需 CL=W/(qS)，Treq=D。可用推力与所需推力不相等时只报告剩余推力，不宣称匀速平飞。
- 爬升/滑翔：同时求解 L=Wcosγ 和 T−D−Wsinγ=0，阻力随该航迹所需 CL 重算。解析二次方程采用避免消去误差的低角度根；|γ|≤20°。滑翔 T=0，γ/垂直速度为负。超出范围、失速与数值失败分别标记，无适用解时不显示有效预测。
- 水平协调转弯：n=secφ，R=V²/(g|tanφ|)，有符号 ω=g tanφ/V；|φ|≤60°。φ=0 时 R/周期没有有限值，显示直线飞行。CLmax 检查与转弯失速速度 Vs√n 同步；尚无瞬态角动力学。

Phase 3：采用机翼与尾翼的线性升力、关于重心的统一力矩，计算 SM = hNP − hCG 和 Cmα = −CLα SM，再联立 L=W 与 Cm=0 求迎角和升降舵。Cm 正为抬头，舵面后缘向下为正；内部角度用 rad。默认中性点约 47.018% MAC、重心 30% MAC、裕度约 17.018% MAC；50 m/s 的配平 α≈2.069°、δe≈−4.314°。零斜率不自动使配平方程奇异，静稳定也不证明动态稳定。失速边界、舵角限制和迎角范围分别检查；未检查前向推力平衡。

Phase 4：坐标实验显示精确 body→NED 旋转，同页提供实际数值线性化：对含 sin θ 恢复项的假想俯仰振子，用中心差分计算配平点的 A/B，与解析导数核对；保持同一输入和初始扰动，用固定 0.01 s RK4 比较非线性与线性角响应、残差和近似误差。该振子不是六自由度飞机。动态模态实验则直接指定频率、阻尼和增长率，组成独立模态的块对角 A 矩阵，显示特征值、时程与相平面；模态幅值不直接等于飞机迎角或侧滑角，矩阵没有从六自由度模型辨识或线性化得到。连续系统的稳定性按特征值判断，数值保护停止只是计算/显示限制。

Phase 5 包含三个独立模型：

- 俯仰闭环：假想二阶 θ–q 对象，手动、PID 与状态反馈；输入 u 是正向抬头的虚拟指令，不是机械升降舵偏角。执行器含位置、速率与滞后限制，条件积分抑制向位置饱和继续累积。超调和调节时间只描述当前有效观察窗。
- 六自由度：机体 x 前、y 右、z 下，NED 北、东、地向下；积分位置、机体速度、角速度及标量在前的 body→NED 单位四元数，每步归一化。固定 0.01 s RK4，使用对角惯量和假想固定气动系数。机械升降舵 δe 与配平章节一致：后缘向下为正，产生低头力矩；飞机参数仍彼此独立。风通过相对空速进入气动力，越过附着流范围暂停。姿态图将四元数旋转后的机体投影到 SVG；另显示北向位移—高度轨迹，不使用 Three.js 场景。
- 高度/速度保持：单独的平面点质点 V–γ–h 模型，直接控制推力和 CL，并考虑限幅与滞后；没有机体姿态状态，也没有控制六自由度飞机。垂直风仅作为 ḣ 中的平流项，不是完整阵风气动力。

基准还包括：默认 q=1531.25 Pa；Phase 1 L=14700 N、速度翻倍升力四倍；Phase 2 平飞所需推力约 828.393 N，Emax≈13.484，最小阻力平飞速度≈38.526 m/s；60° 转弯 n=2、失速速度乘 √2。验证方法与结果见 [验收记录](docs/validation.md)。

## 扩展结构

- `src/content/curriculum.ts`、`phase2.ts`–`phase5.ts`：课程、原创推导、阶段题目与公开资料来源。
- `src/content/questions.ts`：统一题目 schema 与判题函数。
- `src/physics/`：基础、性能、静稳定、模态、俯仰控制、六自由度及点质点保持的纯计算和范围诊断。
- `src/physics/experiments.ts`：基础实验注册与请求/响应边界，供后续 Worker 扩展；其余实验由各实验组件调用纯模型。
- `src/components/LessonPage.tsx`：共享七段教学结构。
- `src/components/PracticePage.tsx`：独立答卷流程，计分/筛选/持久化在 `src/storage/practice.ts`。
- `src/storage/progress.ts`：旧进度兼容和多课程存储。
- `src/App.tsx`：页面与实验组件通过 `React.lazy` 按需加载。
- `tests/`：解析基准、答题和迁移测试；`scripts/browser-smoke.mjs`：真实生产版浏览器验收。

## 尚未覆盖

六级大纲仍有未完成专题：Level 1 其余独立课程、完整稳定性导数推导、完整六自由度飞机的配平/Jacobian 与线性响应对照、基于真实飞机数据的耦合模态、完整多变量控制设计，以及在同一个六自由度对象上的姿态/高度/速度综合自动驾驶。现有数值线性化针对独立俯仰振子；状态反馈是教学 θ–q 反馈，不能当作完整 LQR 或极点配置工具。

尚无真实飞机标定、完整非线性失速/阵风模型、账户与云数据库、实际 Worker 或 Python 数值服务。三维和图表依赖按页面加载，首次进入相应实验仍需要下载这些模块。后续可在保持模型边界清晰的前提下逐项扩展。
