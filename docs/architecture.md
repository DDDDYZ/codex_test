# Phase 1–5 架构与模型边界

知识依赖：直觉与四力 → 动压/气动性能 → 静稳定/配平 → 坐标系/刚体运动/线性化 → 稳定性导数/模态 → 控制系统。Level 4 起需要大学数学。

当前有 14 节课程、43 道题、15 组实验：基础 1 课/3 实验，性能 5 课/4 实验，静稳定 2 课/2 实验，运动方程与模态 3 课/3 实验，控制与综合示例 3 课/3 实验。Phase 4 分属 Level 4–5，Phase 5 属于 Level 6；交付阶段与知识级别不是同一编号。

课程使用共享 `StudyLesson` 七段结构：现象观察、预测、物理解释、逐步公式、交互实验、在线答题、总结。`curriculum.ts` 与 `phase2.ts`–`phase5.ts` 保存内容、变量、假设、任务 ID 和公开参考资料。共享课程完成条件同时检查预测、实验任务与本课题目掌握状态。大纲仍有未完成专题，开放的课程不能代表全部知识点已经覆盖。

模型层是 UI 无关的纯 TypeScript。各模型的参数与状态独立，尤其不能把静稳定飞机、模态幅值、俯仰对象和六自由度飞机视为同一套状态：

| 文件 | 计算对象与边界 |
| --- | --- |
| `models.ts` | 基础升力示意、坐标变换和二维四力增量；固定 0.02 s RK4，非自由六自由度飞行 |
| `performance.ts` | 抛物线极曲线和定常力平衡；爬升/滑翔联立求解，检查 CL 和航迹角范围 |
| `stability.ts` | 固定升降舵的线性机翼/尾翼静稳定；联立升力与俯仰力矩求纵向配平，检查独立操纵能力及包线 |
| `dynamics.ts` | 精确机体→NED 旋转，以及直接给定参数的独立模态块；固定 0.01 s RK4、解析特征值与独立解析响应基准 |
| `linearization.ts` | 含 sin θ 恢复项的假想俯仰振子；实际中心差分 A/B、配平残差，以及固定 0.01 s RK4 的非线性/线性扰动对照 |
| `control.ts` | 假想 θ–q 二阶对象；正抬头虚拟输入 u、手动/PID/状态反馈与有限执行器，固定 0.01 s RK4 |
| `sixDof.ts` | NED 刚体运动、机体速度与角速度、body→NED 四元数；固定 0.01 s RK4、归一化、假想固定气动系数与对角惯量 |
| `autopilot.ts` | 独立 V–γ–h 平面点质点保持；推力/CL 指令、限幅、滞后与条件积分；垂直风只作高度平流 |

静稳定给出初始恢复力矩趋势，动态模态按连续系统特征值判定衰减或增长，配平要求当前力与力矩平衡。它们在界面和课程中分别说明。模态 A 矩阵没有从六自由度模型计算 Jacobian 得到；高度/速度保持也没有控制该六自由度对象。各页明确角度单位、坐标方向与操纵正号：配平与六自由度的机械升降舵 δe 都以后缘向下为正，产生低头力矩；俯仰控制对象则使用正抬头虚拟指令 u，对应机械符号 δe = −u。

坐标页内的 `LinearizationDemo` 实际调用中心差分，逐列求非线性振子的 A/B，而非只显示预写矩阵。振子为 θ̇=q、q̇=−2ζωq−ω²sinθ+Ku，静止工作点取 q0=0、u0=ω²sinθ0/K；内部角度与虚拟输入用 rad，没有执行器限幅。界面显示配平残差、数值 Jacobian、非线性与线性扰动曲线及误差。非线性绝对状态减去工作点后才与线性扰动比较；10 s 响应使用相同初始扰动、输入和 0.01 s RK4 步长。此方法演示仍独立于模态块和六自由度飞机，属于原坐标实验内部内容，不增加实验类型计数。

失速包线、操纵限值和数值/显示保护分别报告。不可行配平不显示为可用解；模态保护停止不改变连续模型的特征值分类；六自由度越过附着流范围时暂停，不推断失速后的运动。控制超调与调节时间基于有效观察窗，尚未建立的指标保持为空。

`App.tsx` 用 Hash 路由组织首页、学习路径、课程和答题，通过 `React.lazy`/`Suspense` 按需加载实验及答题组件。基础和坐标姿态采用 Three.js；六自由度姿态由积分四元数变换机体后，用 SVG 作固定 NED 投影，并显示北向位移—高度轨迹。工程示意、时程和科学坐标图由 SVG/Recharts 表达。参数、模型计算与显示分层，帧率和播放速度不改变物理积分步长。

答题页面有单独 Hash 路由和独立状态：选择题集 → 草稿/答题卡 → 确认交卷 → 评分/解析 → 错题重做。题型使用可判别联合；只在交卷时将正误同步到学习进度。数值题支持负数、小数与科学记数法，拒绝空白、非有限值和非法格式。

持久化：学习记录保留 `fdl-progress-v1` 及原始题 ID，添加可选多课程完成/预测字段；草稿与上次成绩单独保存在 `fdl-practice-v1`。恢复时清理不可信字段和失效题 ID；localStorage 不可用时显示会话保存限制。后续账户存储可替换此适配层。

`experiments.ts` 注册基础实验，请求包含 requestId、experimentId、parameters，并通过响应返回结果或错误。其余实验组件直接调用对应纯模型；当前没有实际 Worker、额外后端或 Python 数值服务。扩展时应先定义物理状态、坐标和有效范围，再增加组件、课程任务和题目。

验证分两层：模型解析基准、平衡残差、坐标/四元数、积分精度、限幅和持久化由单元测试检查；生产版浏览器脚本检查课程/实验/交卷流程、CSV 和手机布局。当前通过情况以 `validation.md` 为准。Windows 启动脚本安装锁文件依赖、做类型检查和单元测试；脚本尚未在实际 Windows 机器验证。

后续仍需完整稳定性导数教学、完整六自由度飞机的配平与 Jacobian、耦合模态及对应线性/非线性响应比较，以及同一六自由度对象上的多变量自动驾驶。现有数值线性化针对独立振子；这些假想模型适合验证所列关系，不能替代真实飞机参数辨识或工程认证。
