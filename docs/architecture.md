# Phase 2 设计与验收

知识依赖：直觉与四力 → 动压/气动性能 → 静稳定/配平 → 坐标系/刚体运动/线性化 → 稳定性导数/模态 → 控制系统。Level 4 起需要大学数学。

已开放基础第一课和五节性能课程。课程使用共享 `StudyLesson` 结构（预测、物理解释、逐步公式、模型条件、实验任务、独立答题入口、总结）。性能课程数据独立维护，后续可以把基础数据统一迁入同一 schema。每一公式与程序共享符号、单位和明确的假设范围。

模型层为 UI 无关的纯 TypeScript。Phase 1 用 RK4，Phase 2 定常性能使用解析关系和稳态力平衡，静态参数变化不伪装成六自由度时间仿真。失速包线、模型边界和数值错误分别报告。

答题页面有单独 Hash 路由和独立状态：选择题集 → 草稿/答题卡 → 确认交卷 → 评分/解析 → 错题重做。题型使用可判别联合；只在交卷时将正误同步到学习进度。数值题支持负数、小数与科学记数法，拒绝空白、非有限值和非法格式。

持久化：学习记录保留 `fdl-progress-v1` 及原始题 ID，添加可选多课程完成/预测字段；草稿与上次成绩单独保存在 `fdl-practice-v1`。恢复时清理不可信字段和失效题 ID；localStorage 不可用时显示会话保存限制。后续账户存储可替换此适配层。

新实验扩展可沿现有注册表、纯计算和可视化组件边界实现。预留 Worker 消息包含 requestId、experimentId、parameters、initialState、dt；Phase 2 计算轻量，没有启动额外后端或 Worker。

验收覆盖模型解析基准/范围边界、题集/数值判题/未答计分、草稿恢复/错题重做、旧进度兼容、共享课程完成，以及生产版真实浏览器与手机视口。Linux 已验证；Windows 脚本保留，真实 Windows 运行仍需用户机器验证。
