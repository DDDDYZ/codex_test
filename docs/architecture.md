# Phase 1 设计与验收

课程依赖：直觉与四力 → 动压/气动性能 → 静稳定/配平 → 坐标系/刚体运动/线性化 → 稳定性导数/模态 → 控制系统。Level 4 起要求微积分、线性代数与 ODE。

第一课按观察、预测、物理解释、逐步推导、实验、理解测试、总结组织。数据与 UI 分离；开发后续阶段时需把逐节结构扩展为共享 Lesson schema，不宣称规划课程已完成。

MVP 验收：三个实验的参数和重置可用，计算/曲线/3D 使用相同输入；失速和姿态奇异性有提示；静态实验即时更新；动态实验固定步长且能暂停/单步/导出；完成一组练习后本地持久化；类型检查、解析基准测试与生产构建通过。

计算层无 React，后续 Worker 可使用 `{experimentId, parameters, initialState, dt, requestId}` 请求、`{requestId, result, diagnostics}` 响应。现阶段不启动不必要的 Worker 或服务。进度存储独立模块，后续可增加账户仓储接口。
