Windows 10/11 启动说明

当前版本包含 Phase 1–5：14 节中文课程、43 道原创题、15 组实验。学习路径按 Level 1–6 组织；各级已经开放相应课程，但六级大纲的全部专题尚未完成。

1. 将整个 ZIP 解压到一个普通本地目录，例如 C:\Projects\FlightDynamicsLab。不要在 ZIP 内直接运行。
2. 双击 windows-start.cmd。脚本会检查 Node.js 22.12+，缺失时尝试使用 winget 安装 Node.js LTS；Windows 可能显示安装权限提示。
3. 如果 winget 不可用，脚本会打开 Node.js 官方下载页面。安装 LTS（包含 npm），然后重新运行脚本。
4. 脚本使用 npm ci 安装锁文件依赖，运行类型检查和全部单元测试，再启动 Vite 并打开浏览器。首次安装需要网络访问 npm 软件源；首次进入三维或图表实验时，浏览器会按需加载相应模块。
5. 保持终端窗口打开，访问 http://localhost:5173；按 Ctrl+C 停止。
6. 后续也可在项目目录终端运行 npm run dev。

本脚本不需要 PowerShell 执行策略调整。已在云 Linux 环境验证项目依赖、构建和浏览器功能；Windows 脚本尚未在实际 Windows 机器运行。若失败，请提供终端的错误文字，不要发送密码或密钥。

更新旧版本：停止旧服务器，下载 GitHub 最新 ZIP，将整个 ZIP 解压到新目录，再运行启动脚本。保持同一浏览器和同一地址 http://localhost:5173，可保留原来的本地学习进度、答题草稿与成绩。不要交替使用 localhost 与 127.0.0.1；更换浏览器、主机名、端口或清除浏览器数据会改变本地存储。

菜单“学习路径”进入课程，“在线答题”打开独立答题页。Phase 3 提供重心/尾翼与纵向配平；Phase 4 提供坐标、假想振子的实际数值 Jacobian 与非线性/线性对照，以及独立动态模态；Phase 5 提供俯仰闭环、假想六自由度与简化高度/速度保持。六自由度姿态与北向位移—高度轨迹使用 SVG 投影。配平和六自由度的机械升降舵均以后缘下偏为正；PID 的 u 是独立的正抬头虚拟输入。所有飞机参数均是假想教学值；振子和模态均独立于六自由度飞机，高度/速度保持使用独立平面模型，没有控制六自由度飞机。进一步说明见 README.md 和 docs\architecture.md。
