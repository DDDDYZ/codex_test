默认基准：q=1531.25 Pa；基础 CL=0.6 时 L=14700 N，速度翻倍使 L 变为 58800 N。性能模型平飞需用推力约 828.393 N，最大 L/D 约 13.484、对应最小阻力速度约 38.526 m/s；60° 水平协调转弯 n=2，失速速度乘 √2。静稳定默认 hNP≈47.018% MAC、SM≈17.018% MAC；50 m/s 配平 α≈2.069°、δe≈−4.314°。

爬升/滑翔此前经独立随机抽查 50,000 组支持范围输入，最大相对力残差约 3.22×10⁻¹⁶。该残差验证方程求解，不证明假设系数代表真实飞机。

## 生产版浏览器验收

`npm run test:e2e` 构建后启动临时 Vite preview，用实际浏览器验证 **8 个场景**，全部通过，无页面/控制台错误：

1. 性能参数、快照、同步受力图、低速失速屏蔽、转弯边界与滑翔 CSV（T 和可用功率均为零）。
2. 43 题完整答卷、100 分成绩、解析、刷新后的成绩和学习掌握状态。
3. 草稿续答、未答确认交卷、错题重练和手机答题卡。
4. 基础课程预测、实验、独立答题、整课完成及刷新恢复。
5. 14 个实际课程路由、公式渲染、Phase 1 旧进度和各课程手机布局。
6. 重心后移、稳定裕度、快照、耦合配平、CSV、舵角限值和无效质量输入。
7. 坐标任务、Euler 奇异位置、实际 Jacobian、小/大扰动响应误差、模态单步/播放、负阻尼、螺旋正负增长率和 CSV。
8. PID 指令限幅、真实响应与快照、手动模式、保持环目标/垂直风、六自由度精确配平、负机械升降舵引起抬头、四元数/CSV 和恢复默认参数。

390 px 手机视口没有页面横向溢出。长公式和表格保留局部滚动；图表用 ResizeObserver 更新宽度。截图与 CSV 位于被 Git 忽略的 `test-results/`。

## 范围与限制

各页面按需加载，三维与主应用依赖仍有大于 500 kB 的构建块提示；这不是构建失败。模型均为假想教学参数：静稳定、约化模态、非线性俯仰振子、PID 对象、点质点保持与六自由度飞机各自独立。统一机械升降舵以舵面后缘向下为正，PID 使用正抬头虚拟量 u；六自由度附着流包线外暂停，不预测失速运动。

验证证明当前机器的计算、交互、构建与浏览器流程通过；不代表真实飞机校准、飞行安全认证、实际 Windows 启动验证、网站部署或新任务环境恢复。后续环境仍须重启服务；保存云配置草稿和发布环境是不同操作。
